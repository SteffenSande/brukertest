# Kildeark: Lojal (kundeklubben, modul 7)

| | |
|---|---|
| **System** | Lojal, kundeklubben (medlemmer og nivå) |
| **Eier** | Kundeklubbansvarlig, Marked |
| **Leveransemåte** | Fullt uttrekk hver dag |
| **Når** | Hver dag kl. 04:00 |
| **Tabeller** | `medlem` |

## Format (det koden trenger)

| | |
|---|---|
| Filformat | JSON, én rad per linje |
| Datoformat | ISO, `yyyy-MM-dd` |

## Kjente svakheter
- Personopplysninger (navn, postnummer). Alle er oppdiktet i kurset, men klassifiseringen må tas på alvor (modul 8).
- Et medlem kan bytte nivå (`BRONZE`, `SILVER`, `GOLD`) og flytte.
