| | |
|---|---|
| **System** | Felles kalender for 2026 og 2027 |

## Format (det koden trenger)

| | |
|---|---|
| Filformat | CSV med overskriftsrad |
| Skilletegn | `,` |
| Datoformat | ISO, `yyyy-MM-dd` |

## Kjente svakheter
- `HELLIGDAG` er `J` bare for offentlige helligdager, ikke vanlige søndager.
